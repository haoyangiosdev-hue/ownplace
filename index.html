Ownplace

Your AI, on your own server.

Ownplace is a personal AI that lives on a server you own. We don't run servers: the app sets up your server over SSH, and from then on your conversations, records and memories stay there.

Getting started

  1. Rent a small Linux cloud server (1 CPU / 2 GB RAM is enough) that you can log into with SSH as root.
  2. In your cloud provider's firewall / security group, allow inbound TCP 22 (setup), 9443 (the app connects to your server) and, if you want friends, 8443.
  3. Open Ownplace, choose Own server, enter the server address, user, password and port, then tap Connect & deploy. The password is used only for this login.
  4. Set up a model: your own inference server, or an API key from a provider you trust. You can also skip and do it later.

Common questions

The app can't reach my server during setup

Check the address and port, and that port 22 is open in your security group.

Setup finished but the app can't connect to my node

Allow inbound TCP 9443 in your security group.

Friends can't reach me

Allow inbound TCP 8443. You can still reach friends without it.

“No model set yet”

Open the role's settings and pick a model, or add one under My machine → Models & keys.

“Your node's certificate changed”

Use Check again over SSH in the app. If you didn't reinstall the node yourself, don't continue — something may be between you and your server.

Does anything get sent to a third party?

Only if you choose a third-party model, and only after you agree for that specific role and provider. See the Privacy Policy.

所在之处

你的 AI，住在你自己的服务器上。

开始使用

  1. 准备一台能用 SSH 以 root 登录的 Linux 云主机（1 核 2G 就够）。
  2. 在云服务商的安全组 / 防火墙放行入站 TCP 22（部署）、9443（App 连接）；要用好友功能再放行 8443。
  3. 打开 App，选「自有主机」，填服务器地址、用户、密码、端口，点「连接并部署」。密码只用这一次。
  4. 配一个模型：你自己的推理服务器，或你信得过的服务商的 API key；也可以先跳过。

常见问题

部署时连不上服务器：检查地址、端口，以及安全组是否放行 22。
部署完连不上节点：放行 9443。
好友连不上你：放行 8443（不放行你仍能主动连好友）。
「还没配模型」：在角色设置里选一个，或到「我的机器 → 模型与密钥」添加。
「节点证书变了」：用 App 里的「经 SSH 重新核对」；如果你没有自己重装节点，先别继续。

はじめかた

  1. root で SSH ログインできる Linux クラウドサーバーを用意します（1 CPU / 2 GB RAM で十分）。
  2. セキュリティグループで受信 TCP 22（セットアップ）と 9443（アプリ接続）、友だち機能を使う場合は 8443 を許可します。
  3. アプリで「自分のサーバー」を選び、アドレス・ユーザー・パスワード・ポートを入力して「接続してデプロイ」。パスワードはこのログインにのみ使用します。
  4. モデルを設定：自前の推論サーバー、または信頼できる提供元の API キー。後からでも設定できます。
